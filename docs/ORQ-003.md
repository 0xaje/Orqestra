# ORQ-003 — Live funding and permission preflight

Run: `npx tsx src/preflight.ts <YOUR_PUBLIC_SS58_ADDRESS>`.

This read-only utility reports current balance/account nonce and selected runtime deposit constants. It never requests a mnemonic or signs transactions.

Do not select an asset ID until a storage query verifies availability. Deposits and fees are denominated in raw units; consult chain decimals before presenting a human-readable amount. The presence of pallet methods does not prove that the signer can execute them.

Status: committed but not yet run against the user's testnet account.
