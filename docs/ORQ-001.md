# ORQ-001 — Live capability verification

## Objective
Determine the Portaldot V3 runtime features that are actually accessible. Do not assume WASM, EVM, or cross-environment atomicity.

## Acceptance criteria
- Native RPC returns chain, finalized block hash, runtime spec name/version.
- Runtime metadata exposes available calls for utility, assets, balances, contracts, evm and ethereum, or explicitly reports absence.
- EVM RPC returns chain ID 420420777 and current block height.
- RPC failures return a nonzero exit status.
- Save timestamped evidence with block hash and runtime version.
